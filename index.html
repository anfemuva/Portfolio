Metric definitions and sample data

Each row represents a month and channel. Delivered counts exposures. Click rate is clicked exposures ÷ delivered exposures. Action rate is completed actions ÷ delivered exposures. Each exposure contributes at most one click and one action, and every action follows a click. Rates use summed counts within each selection. Recipients may appear in multiple exposures.

Python validation and SQL aggregation

Save the sample CSV as engagement.csv. This Python script checks duplicate month/channel pairs and impossible counts, then loads the rows into SQLite and runs the KPI query.

import csv
import sqlite3

with open("engagement.csv", newline="", encoding="utf-8") as file:
    rows = list(csv.DictReader(file))

records = []
seen = set()
for row in rows:
    key = (row["month"], row["channel"])
    if key in seen:
        raise ValueError(f"Duplicate month and channel: {key}")
    seen.add(key)

    delivered = int(row["delivered"])
    clicked = int(row["clicked"])
    actions = int(row["actions"])
    if not 0 <= actions <= clicked <= delivered or delivered == 0:
        raise ValueError(f"Invalid engagement counts: {key}")
    records.append((*key, row["quarter"], delivered, clicked, actions))

query = """
SELECT
    channel,
    SUM(delivered) AS delivered,
    ROUND(100.0 * SUM(clicked) / NULLIF(SUM(delivered), 0), 2) AS click_rate,
    ROUND(100.0 * SUM(actions) / NULLIF(SUM(delivered), 0), 2) AS action_rate
FROM engagement
WHERE quarter = ?
GROUP BY channel
ORDER BY click_rate DESC;
"""

with sqlite3.connect(":memory:") as db:
    db.execute("""
        CREATE TABLE engagement (
            month TEXT,
            channel TEXT,
            quarter TEXT,
            delivered INTEGER,
            clicked INTEGER,
            actions INTEGER,
            PRIMARY KEY (month, channel)
        );
    """)
    db.executemany("INSERT INTO engagement VALUES (?, ?, ?, ?, ?, ?)", records)
    for result in db.execute(query, ("Q2",)):
        print(result)
